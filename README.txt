SMARTBILL PRO — QUICK START
============================

1. Extract smartbill_pro.zip to a folder.
2. Double-click index.html to open it in Chrome, Edge, or Firefox.
3. Fill in your business and client details, add line items, tax and discount.
4. Click "Print / Save PDF", then choose "Save as PDF" in the print dialog.
5. Click "Save document" to save a record in this browser.
6. Use "Export backup" to download a JSON backup. "Import" restores a backup.

IMPORTANT
- This is a working starter version, not a hosted multi-user SaaS.
- Saved records stay in the browser's local storage on this device/browser.
- Clearing browser site data can remove saved records; export backups regularly.
- For client sales, customize the brand, test the app, and disclose that this version
  stores data locally. Cloud sync, login, online payments, and server-side security
  are not included in this starter version.
- PDF generation uses your browser's Print dialog; select "Save as PDF".
